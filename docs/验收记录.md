## 本机验收建议

先运行默认模式并完成示例分析；然后执行 `mvnw.cmd test` 与 `py -3.10 scripts/smoke_test.py`。最后分别接入真实模型、MySQL和Redis，逐项记录效果。

出现问题可提供终端完整错误和操作步骤。不要只截最后一行“启动失败”；其前方的异常信息往往能定位原因。
