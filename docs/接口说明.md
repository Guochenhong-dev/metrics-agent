# 接口说明

默认地址：`http://127.0.0.1:8082`。除页面资源和CSRF初始化外，业务接口需要登录。

## 认证

1. GET `/api/csrf`，保存Cookie和响应中的token、headerName、parameterName。
2. POST `/api/login`，用表单提交username、password和CSRF参数。
3. 登录成功后重新GET `/api/csrf`取得新令牌，后续写请求携带headerName对应的token。
4. POST `/api/logout`登出，同样需要CSRF。

完整可运行例子在 `scripts/smoke_test.py`。

## 路由

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/config | 当前用户权限、数据版本和范围、指标与维度目录 |
| POST | /api/plan | 将自然语言解析为计划预览 |
| POST | /api/reports | 校验并执行计划，保存报告 |
| GET | /api/reports | 本人最近30份报告 |
| GET | /api/reports/{id} | 本人报告完整JSON |
| GET | /api/reports/{id}/export?format=md | Markdown报告 |
| GET | /api/reports/{id}/export?format=csv | 主维度明细CSV，含UTF-8 BOM |
| GET | /api/admin/audit | 管理员查看最近100条分析调用记录 |

计划预览请求：

```json
{"question":"最近7天净实收为什么下降，按区域分析"}
```

执行分析请求：

```json
{
  "question": "最近7天净实收为什么下降，按区域分析",
  "plan": {
    "metric": "net_receipts",
    "dimension": "region",
    "startDate": "2026-08-25",
    "endDate": "2026-08-31",
    "region": null,
    "category": null,
    "channel": null,
    "status": null
  }
}
```

可用指标：net_receipts、paid_amount、refund_amount、order_count、cancellation_rate、fulfillment_rate。

可用维度：region、category、channel、status。

筛选值：

- region：华东、华北、华南；还受登录用户权限限制。
- category：空调、洗衣机、热水器。
- channel：自然流量、广告、合作。
- status：PENDING待支付、PAID已支付待履约、CANCELLED已取消、FULFILLED已履约。

null表示不额外筛选，不能取消服务端授权区域限制。

## 返回字段

报告包含id、owner、scope、question、createdAt、analysis、narrative、narratorMode、cacheHit、sqlCount和durationMs。

analysis包含当前/前期数据、变化、贡献、趋势、指标口径、数据版本和E1—E4证据。numerator/denominator为聚合计算的原始分子、分母，金额底层单位为分。比例值的单位是百分比，例如40表示40%，不是0.4。

narrative只是辅助解释；图表和数值取analysis。模型返回的数字不写回analysis。

## 错误

| 状态码 | 意义 |
| --- | --- |
| 400 | 计划、日期、指标或筛选无效；额外SQL字段不接受 |
| 401 | 未登录/登录失效 |
| 403 | CSRF失败、越权区域或历史报告超过当前权限 |
| 404 | 报告不存在或不属于本人 |
| 429 | 查询预算耗尽 |
| 500 | 服务异常，查看服务端日志 |

后端不提供任意SQL接口、业务数据修改接口、报告公开分享接口。重复分析可以生成不同报告快照，计算结果可能命中缓存；此场景不按建单式幂等处理。
